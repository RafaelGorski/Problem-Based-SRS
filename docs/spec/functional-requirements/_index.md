## Verification tracks

- **App track — Playwright with screenshots.** `--project=canvas` and `--project=site`
  in `.github/extensions/srs-navigator`. For claims about a *published* release, the
  server must be booted from the extracted archive and the PNG attached with its
  `provenance.json`.
- **Skills track — CLI.** `issue-ledger.mjs`, `closure-evidence.mjs`,
  `check-distribution.mjs`, `run-tests.ps1`, `build-plugin.py validate`. Findings are read
  separately from the exit code.

Requirements gated on issue or release **metadata** (FR.04.1.12, FR.04.1.14, FR.04.1.15)
declare the browser explicitly out of scope. Recording that boundary is part of the
deliverable, not an omission.
