  must be booted from the **extracted archive** and the PNG attached with its

  artifact.

  `check-distribution.mjs`, `issue-ledger.mjs`, `release-train.mjs`, and the
  `node --test evals/tests/*` files. Findings are read **separately from the exit code**,
  because the distribution monitor exits 0 on warnings by design.
