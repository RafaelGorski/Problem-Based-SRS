# NFR.03: Time to first graph

## Requirement

**ID:** NFR.03
**Title:** Time to first graph
**Category:** Usability
**Priority:** Must Have
**Status:** Draft

### Statement

The documented install path shall bring a first-time user from a clean profile to a rendered SRS graph within five minutes.

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN.02.1 | A first-time user needs the documentation to state every install required before /live, in the order they must happen. |
| Customer Problem | CP.02 | The documented first run does not reach the product's headline capability |
| Applies To FRs | FR.02.1.1, FR.06.1.8 | Requirements this quality attribute constrains |

## Measurement Criteria

- **Target:** Median time-to-first-graph <= 5 minutes
- **Minimum Acceptable:** 4 of 5 observed sessions complete without leaving the documented path
- **Measurement Method:** Timed observation of clean-profile sessions, with a screenshot of the first rendered graph

## Acceptance Criteria

- [ ] Median time-to-first-graph across observed sessions is <= 5 minutes
- [ ] At least 4 of 5 sessions complete using only the documented path
- [ ] Each completed session has a timestamped screenshot of the first rendered graph
